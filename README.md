## Featured Projects

### AbilityScan — Inclusive Recruitment Platform

An inclusive recruitment platform designed to support employment opportunities for Persons with Disabilities (PWD).

**Key Features:**
- Five-layer rule-based job matching engine.
- Explainable candidate-job matching results.
- QR code digital portfolio for job seekers.
- Role-based access for Admin, Employer, and PWD users.
- Adjustable matching parameters for greater transparency.

```bash

```

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html` using the **Live Server** extension or another local HTTP server.
