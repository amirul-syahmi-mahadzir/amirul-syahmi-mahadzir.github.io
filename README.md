# Personal Portfolio — Amirul Syahmi Mahadzir

A personal portfolio website showcasing my technical skills, academic achievements, certifications, and projects as a Bachelor of Computer Science (Hons.) Netcentric Computing student at Universiti Teknologi MARA (UiTM), Shah Alam.

## Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive layouts
- Git & GitHub — Version control and source code management
- GitHub Pages — Static website hosting

## Featured Projects

### AbilityScan
An inclusive recruitment platform for Persons with Disabilities (PWD), featuring a five-layer rule-based job matching engine and QR code digital portfolios.

**Technologies:** Laravel, Vue.js, MySQL, Nginx, Ubuntu.

### Internship Finder System
A web and mobile platform connecting students with companies offering internship opportunities.

**Technologies:** Laravel, MySQL, Flutter.

### Smart Garbage Collector
An IoT project involving a smart bin and a robotic garbage collector using Arduino, sensors, and hardware integration.

## Portfolio Sections

- About Me & Technical Skills
- Featured Projects
- Certifications & Achievements
- Education Timeline
- Contact — LinkedIn & GitHub

## Running Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or a local HTTP server.
